# ⚡ Wiochord Lossless ⚡

Multi-catalog Lossless and Hi-Res music modules with automatic failover.

**[Manifest URL](https://raw.githubusercontent.com/Wiojelt/WioLand/main/bitchord/manifest.json)** · **[Website](https://wiojelt.github.io/#bitchord)** · **[BitChord](https://github.com/kushagrasinghx/BitChord)** · **[Dial (Fork)](https://github.com/steeben/Dial)**

</div>

## Installation

1. Remove any older Wioland source, if installed.
2. In BitChord or Dial, open **Settings → Sources → Add an addon**.
3. Paste the manifest URL below and save. Detected as a module index.

```text
https://raw.githubusercontent.com/Wiojelt/WioLand/main/bitchord/manifest.json
```

## Sources (Çoklu Katalog Kayıpsız Kaynaklar / Multi-Catalog Lossless)

1. **⚡ Wiochord Lossless ⚡** `~350ms` (Tidal + Telegram Hi-Res otomatik yarış ve failover)
2. **Dial Monochrome FLAC** `~500ms` (Doğrudan Tidal 16-bit 44.1kHz FLAC akışı)
3. **PencariMusic Hi-Res 24-bit** `~600ms` (24-bit 96kHz / 192kHz stüdyo master FLAC & zengin Türkçe/global katalog)
4. **Internet Archive FLAC** `~800ms` (960.000+ canlı konser, nadir kayıt ve açık FLAC arşivi)

Tek bir backend yerine bağımsız ve çalışan 4 farklı ağ üzerinden parça eşleşmesi ve gerçek FLAC aktarımı sağlanır.
